# verbalingo-web

Собранная веб-версия **Verbalingo** — тренажёра английского для русскоязычных.

Открыть: <https://app.verbalingo.uk/>

Здесь нет исходников: только то, что выдал `flutter build web` — скомпилированный
`main.dart.js`, ассеты и колода. Код приложения лежит в отдельном закрытом
репозитории, и этот существует ради одного: GitHub Pages не раздаёт закрытые
репозитории без платного тарифа, а страница должна открываться у всех.

Правки сюда руками не вносятся — всё содержимое перезаписывается целиком при
каждой выкладке (`tool/deploy_web.sh` в репозитории приложения). Переживают
перезапись только этот файл и `CNAME`.

## Что это за приложение

Интервальное повторение с продуктивным вводом: слово не выбирается из
вариантов, а печатается в предложении. Планировщик — FSRS-6.

Прогресс лежит в браузере, в `localStorage`. Никуда не отправляется, пока вы не
войдёте в аккаунт: вход существует ради одного — заниматься по тому же
расписанию и на телефоне тоже.
